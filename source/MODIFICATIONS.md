# 奶蛙透明桌宠

当前 OBS 版本已改为真正的 `input-overlay` 输入叠加源，配合 OBS 内的原生动画滤镜。此前 `obs-overlay/` 的网页实现已清理，其开发过程保留在本修改记录中。安装与文件说明见 `obs-native/README.zh.md`。

从 GitHub 重新克隆 `malad1211/Mania-Cat`，基线提交为 `7087962223b49ee29a51ce06be98d5195dc39607`。此次修改位于 `Mania-Cat-Transparent`，未使用旁边 `Mania-Cat` 目录中的修改版源码。

以 `assets/milk-frog/approved-preview.png` 为角色参考，通过内置 imagegen 生成四帧真正带 alpha 的素材，再打包为原项目的九张 PNG。原始图集为 `assets/milk-frog/atlas.png`；中性图集 `atlas-unlit.png` 移除了键帽发光和手部蓝色反光。当前版本使用内置 imagegen 编辑得到的 `atlas-raised-arms.png`：待机时抬高整个前臂，按下时整条前臂明显下压，保持原有键位接触位置、角色面部和朝向。最终注册后的素材位于 `assets/milk-frog/sprites/` 和 `SFML/SFML/`。提示词记录在 `生成提示词.txt` 和 `前臂增强提示词.txt`。

按键保持原来的两手各四种状态，默认改为 D/F/J/K。按图中的透视，D/F 在画面右侧，J/K 在画面左侧。主体和两手覆盖图组合出 16 种按键状态；粒子和键帽文字对应当前配置。

当前素材改为完整固定躯干与键盘底图，加上只含双臂的姿势覆盖图。此前覆盖图包含部分肚皮和躯干，导致不同按键的肚皮色度变化，以及按 F 时右下轮廓出现缺口；现在这些区域统一来自同一张底图。

早期透明静态躯干图集为 `assets/milk-frog/atlas-static-body.png`，当前保留为历史素材。`atlas-arm-mask.png` 是内置 imagegen 制作的技术分割遮罩，用纯洋红标记头、躯干和键盘，只用于判断双臂边界；遮罩颜色不进入成品。`PackAssets.cs` 保留原坐标，处理半透明手臂边缘并剔除旧键帽残片。两次编辑均使用真正透明背景；完整提示词记录在 `assets/milk-frog/固定躯干提示词.txt`。最终九张透明 PNG 位于 `assets/milk-frog/sprites/` 和 `SFML/SFML/`。

肚皮与右臂交界修正：当前所有双臂均使用 `atlas-raised-arms.png` 与 `atlas-arm-mask.png`。内置 imagegen 编辑的透明固定躯干为 `assets/milk-frog/atlas-body-fitted.png`，提示词保存于 `assets/milk-frog/肚皮贴合提示词.txt`。躯干和整个键盘直接使用这张图的同一帧，不在键盘轮廓附近替换另一张图的肚皮 RGB，消除键盘后沿的斜直线色差。原面部保持不变；仅在源图第 200–219 行混合颈部颜色，平滑下颈部与躯干图的接合。

前一版 `atlas-right-arm-joints.png` / `atlas-right-arm-joints-mask.png` 的修法未解决交界问题，并且固定肩部与移动上臂两层在颈部留下尖角；这些素材保留为历史记录，当前打包不再使用。当前先将肩部裁切在颈部附近，再用连续曲线补齐上臂与颈部间缺失的连接像素，保留圆润的手掌轮廓。手指和前臂的主体保持原素材。

轮廓裁切：`FitTorsoContours` 在源图第 195–265 行拟合连续的左右颈肩边缘，并在第 310–460 行将肚皮左缘接成连续曲线。每个边缘像素使用亚像素 alpha 覆盖率，新增边缘 RGB 来自相邻的有效像素。原先在第 355 行突然收窄肚皮造成的前臂下方缺口，以及键盘上方的矩形肚皮残片，都通过实际轮廓修正去除。肩部外缘采用预乘 alpha 的小范围滤波，避免透明像素引入黑边。

键帽文字：字号从 28 提高为 44，四个键帽顶面中心在原生画布中为 D=(694,543)、F=(594,526)、J=(498,510)、K=(408,495)。字体实际边界框中心对齐这些位置，保持朝角色方向的透视。文字先绘制，再绘制双手，按下时由手指自然遮挡文字。

`ParticleEffects.hpp` 使用程序生成的柔和径向光晕纹理绘制暖金黄色粒子、奶白色亮芯、细小星芒与短尾迹。每次敲键爆发为 96 个，持续发射约每秒 180 个。粒子轨迹使用三维位置、速度与重力，投影到斜向键盘平面，深度影响大小、亮度和手部前后的遮挡，并加入扩散冲击光环。系统按键重复不会再次爆发。粒子数量上限 2048，完全渐隐后停止刷新。光效单独合成，不改变键盘素材，窗口仍使用真正的透明 alpha。

黑线根因：此前身体、左右手和键盘各自缩放，互补的透明裁切边缘在双线性采样时同时变成半透明，露出背景。现在先在 1189×880 原像素坐标上合成完整 RGBA 图，再整体缩放；使用预乘 alpha 混合，避免再次乘 alpha 导致暗边。原尺寸预览不能发现此问题，因此补充全部可达缩放档位的验证。

`Source.cpp` 保留 SFML 素材加载与绘制，改用离屏透明渲染和 Windows layered window 显示。键盘监听与渲染在同一个消息循环中执行，避免原代码分离线程修改纹理的问题。支持左键拖动、滚轮缩放、右键置顶/退出/重新加载配置。窗口没有标题栏，角色与键盘外的区域透明。

构建：`./build.ps1`。依赖 Visual Studio C++ 和 SFML 2.6.2；构建脚本会从 SFML 官方地址下载所需版本，并将运行 DLL 复制到可执行文件旁边。

前臂验证：每只按下的手均至少有 1,200 个黄色前臂像素发生明显变化，深色手指中心相比待机至少下移 70 个原尺寸像素，排除仅弯曲手指的细微动作。

补充回归检查：实际渲染图中 x=174–177、y=473–475 的 12 个背景像素必须透明，覆盖旧检查结束位置之后的键帽交界。上一版轮廓与键帽修正版运行包提取至 `build/key-rear-before/` 作为负例，用新验证器可复现 `Belly tab retained by first-key mask: x=174,y=473`。新素材通过该检查和全部 16 种姿势、30 档尺寸检查。`tools/MakeKeyRearPreview.ps1` 从旧版及新版程序的实际输出裁出相同位置，生成 `assets/milk-frog/key-rear-verification.png`，仅用于检查和展示。

手臂内缘抗锯齿：`SmoothIdleInnerEdge` 只处理抬起的右前臂与奶白肚皮相接的透明边缘。源图第 300–365 行的内缘使用预乘 alpha 的 5×5 小范围滤波，首尾渐变过渡；内部 RGB、固定肚皮和键盘不参与滤波。`inner-edge-verification.png` 是处理前后的实际渲染同位置放大图。

粒子喷泉：各按键的发射原点改为实际指尖与键帽接触的位置。D/F 同时按下与 J/K 同时按下各有不同的指尖锚点；16 种姿势的验证会确认每个有效发射原点附近存在深色手指像素。每颗粒子在生成时记录原点，之后改变手势不会移动已有粒子。生成范围缩小到指尖附近，采用向上的初速度和重力产生喷泉弧线，混合较高的细光束、大小不同的金色亮点、短尾迹与星芒；光晕和扩散圈也使用指尖锚点。保留手臂前后的两次深度绘制。

刷新优化：`FrameWaiter` 使用高精度可等待计时器，按上一帧开始时间计算剩余等待时间，目标 120 帧/秒，移除绘制后额外固定等待 16 毫秒的做法。按键消息可立即唤醒，首次按键不会把长时间待机的时长计入粒子运动。效果消失后恢复无限消息等待。每次粒子深度绘制最多提交三批顶点，重复使用预留的缓冲区，避免逐颗创建圆形、星形和尾迹对象。

性能验证：`--benchmark-particles` 在隐藏的透明窗口中使用真实的渲染、GPU 图像读回、BGRA 转换和 `UpdateLayeredWindow` 路径，同时持续按下四键。新版喷泉在 380、600、800 像素尺寸的平均渲染耗时分别为 1.73、2.82、4.80 毫秒；使用同一计时器测得约 117.0、117.0、116.8 帧/秒。这是当前设备上的渲染与等待测试，明细保存在 `assets/milk-frog/performance-verification.csv`。所有尺寸的第 95 百分位帧间隔约 8.78–8.84 毫秒。

动画预览增加到 60 帧/秒，同时输出 GIF 和 `particle-preview.mp4`，时长 7.2 秒，包含松开后完整回落与渐隐过程。预览背景仅用于展示，桌宠继续使用真正透明的素材和窗口。

高喷泉与密度调整：主光束按各指尖原点与脖子高度的距离计算向上初速度，使透视位置不同的四个键都喷至相近高度。重力为 600 原生像素/秒²，粒子寿命为 2.15–2.50 秒，保留完整上升与回落过程。单次爆发从 64 颗增至 96 颗，持续发射从约 107 颗/秒增至约 180 颗/秒，粒子上限提高至 2048。

高度验证：在喷发后 0.8 秒和 1.0 秒检查实际渲染出的可见粒子。15 种有效按键组合全部进入脖子高度范围，最高可见像素 y 为 209–216；原生完整画布的高度为 880。明细为 `assets/milk-frog/fountain-height-verification.csv`，对应渲染图片位于 `dist/milk-frog-4k/verification/fountain-height-1.png` 至 `fountain-height-15.png`。新版密集喷泉的性能记录已更新，持续四键发射时仍测得约 116 帧/秒。

F/J 落点调整：单独按 F 或 J 时，保持肩部位置，以平滑权重让下臂向键盘中间伸出，末端手指保持原形。F 的末端移动量为 (-57,+11)，J 为 (+29,+13) 原生像素，分别落在键帽中心 (594,526) 与 (498,510)。两者一起按下时同时生效；同一只手同时按 D+F 或 J+K 时沿用双键姿势。
