# OBS 奶蛙一键安装

[English](README.en.md) · [项目首页](../README.md)

## 推荐：选择场景，一次安装

1. 双击上一级目录的 **MilkFrogOBS.exe**。
2. 选择“场景集合 / 场景”，填写奶蛙源名称，点击“安装到所选场景”。更新时选择“更新指定的已有一体奶蛙源”并填写该源名称。
3. 首次安装后正常重启 OBS，并打开所选场景集合。奶蛙自动加入指定场景，不会改投当前场景。若插件已加载，通常可直接生效。

新增的是一个“奶蛙（敲键、粒子、笑声一体）”原生源，已经包含透明画面、全局敲键、黄色粒子、大笑视频和声音。**不需要安装 input-overlay，也不需要手动选贴图、配置、滤镜或再加音频源。** 重复添加同名的一体源不会重复生成场景项；更新保留原位置、大小和可见状态。其他类型的同名源会拒绝覆盖。

打开奶蛙源的“属性”，点击“修改模式、键位与大笑快捷键…”设置 4K–8K 和快捷键。声音默认只送入直播/录制，监听关闭，可在 OBS 混音器调音量或静音。无需运行桌宠。

一键安装包使用 Windows OBS 33 的插件目录。标准版写入 `%ProgramData%\obs-studio\plugins\milk-frog-easy`，便携版写入 OBS 安装目录下的 `plugins\milk-frog-easy`。安装时需有该目录的写权限，并保留 EXE 旁完整的 `obs-input-overlay` 文件夹。安装会复制素材并保留已有键位，之后可以移动下载目录。

**让智能体辅助安装：** 把上一级目录的 [agent.md](../agent.md) 交给它。脚本支持先列出实际场景，再指定场景集合、场景及源名称静默安装；不会弹窗、启动或强制关闭 OBS。

```powershell
powershell.exe -NoProfile -NonInteractive -ExecutionPolicy Bypass -File ./obs-input-overlay/InstallObsEasy.ps1 -ListTargets -Quiet -Json
```

DLL、JSON、EXE 不能拖入 OBS 预览区成为这个原生源；直接拖入静态图片或网页也不能替代全局敲键和原生音频。

## 查找并卸载奶蛙

1. 双击 **MilkFrogOBS.exe**，点击左下角 **“查找 / 卸载奶蛙”**。
2. 查看查找结果中的“场景集合、源名称、类型、所在场景 / 分组 / 源”，勾选要卸载的奶蛙。悬停可查看全部位置；同一个源被多个场景共用时，会一起列出，卸载会从这些位置全部移除。
3. 下方独立的“插件 / 素材目录”列表显示实际路径、大小和旧路径副本；即使场景里已没有奶蛙源，也能查到遗留文件。
4. 正常关闭 OBS 后点击“重新查找”，再勾选并点击“执行卸载 / 清理”。运行中的 OBS 不会被强制关闭。

默认保留插件、素材和 OBS 键位，方便以后再装。若要完整移除一键版文件，再勾选 **“同时清理一键版插件、OBS 素材和键位”**；只有全部奶蛙源和待安装请求都被选中或已移除时才允许清理。已在 OBS 中手动删除所有奶蛙源，也可用此选项清理遗留文件。桌宠共享配置和下载目录保留；手动安装的旧版 DLL 不在一键版文件清理范围内。

卸载会先备份场景配置和取消的安装请求，备份路径会显示在结果中。旧版奶蛙滤镜只移除滤镜，承载它的其他源会保留；旧版笑声音频可单独选择。智能体可按 [agent.md](../agent.md) 使用只读查找与静默卸载命令。

## 旧版手动安装方式

以下仅供已有 input-overlay 集成继续使用；新安装请使用上面的一键入口。

使用真正的 `input-overlay` 输入叠加源，配合“奶蛙 DFJK · 原生动作与粒子”原生滤镜。它在 OBS 内捕获当前模式的全局敲键并绘制 4K / 5K / 6K / 7K / 8K 的 16 / 32 / 64 / 128 / 256 种手臂组合、按住时的大笑表情和黄色喷泉粒子。直播期间无需运行桌宠、网页或后台服务。

## 快捷修改 OBS 键位和重开大笑键

双击本目录的 **MilkFrogKeySetup.exe**（无需运行桌宠）。先选择 4K–8K，再点击对应位置录入敲键，或点击“重开大笑键”录入 F5、Ctrl+Q、Ctrl+Shift+Q 等组合，松开全部按键后点击“保存并应用”。

工具自动更新 `keybindings.json`、`key-labels.png` 和 `milk-frog.png`；原生滤镜约 0.3 秒内自动切换绑定与键帽文字，无需重启 OBS。恢复当前模式默认键 / 恢复 F5 后也要保存。关闭工具不会保存尚未提交的修改。

支持左右 Ctrl/Shift/Alt/Windows、空格及其他功能键，沿用 LC/RC、LS/RS、LW/RW、SPC、ENT 等最多三字符缩写。各轨道敲键不能重复或相互重叠，大笑组合也不能包含敲键。大笑组合最多 8 个键，按住不重复触发；敲键立即中断视频及配音。

OBS 模式和敲键保存在本目录，与桌宠配置独立；重开大笑键仍保存在 `%LOCALAPPDATA%/MilkFrog/config.txt`，与桌宠共享。请保留完整目录中的无字母图集及 `milk-frog-unlabeled.png`，不要只下载改键 EXE。

## 安装

1. 安装官方 [input-overlay 插件](https://github.com/univrsal/input-overlay/releases)。开发验证使用 input-overlay 5.0.5。
2. 将本目录的 `milk-frog-native.dll` 复制到 OBS 安装目录的 `obs-plugins/64bit/` 下，然后重启 OBS。提供的 DLL 面向 **64 位 Windows、OBS 32.2.2**。
3. 将本素材目录放在固定位置，保留所有文件，不要分开移动。
4. 添加“输入叠加”源：贴图选择 `milk-frog.png`，配置选择 `milk-frog.json`，输入源使用本机输入。
5. 打开该源的“滤镜”，添加“奶蛙 DFJK · 原生动作与粒子”，配置选择同一个 `milk-frog.json`。
6. 调整源的位置和大小。
7. 添加“奶蛙 · F5 笑声音频”原生音频源，文件选择本目录的 `laugh.wav`，在高级音频属性中将监听设为“监听关闭”。

仅让观众看到：关闭 OBS 预览，角色仍进入直播/录制输出；无需启动桌宠 EXE。

## 行为

- 按住 D/F/J/K：对应整条前臂按下、闭眼大笑、黄色喷泉粒子。全部松开恢复微笑，已产生的粒子约 0.40 秒内淡出。
- F5：播放一次 9 秒透明捧腹大笑视频与配音；再次按下从头播放，长按不重复触发。按任意 DFJK 立即停止视频与配音，恢复敲键动作。播放结束回到待机。
- 在桌宠托盘的“重开大笑键”中保存 Ctrl+Q 等新组合，OBS 会自动同步，无需重启或持续运行桌宠。
- 默认键位：4K 为 DFJK，5K 为 SDFJK，6K 为 SDFJKL，7K 为 ASDFJKL，8K 为 ASDFJKL;；可用本目录的改键工具切换模式和修改。

`milk-frog.json` 使用相对路径寻找图集。必须保留 `milk-frog.png`、JSON、body-parts.png、desk-parts.png、hand-parts.png、shadow-parts.png、`laugh-frames.mfa` 和 `laugh.wav`。构建方法见 [插件源码说明](../source/obs-native/README.en.md)，许可证见 [LICENSE.txt](LICENSE.txt)。
