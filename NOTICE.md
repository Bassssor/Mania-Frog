# Upstream credits and component licenses

Mania-Frog is a modified Windows companion based on [malad1211/Mania-Cat](https://github.com/malad1211/Mania-Cat), using upstream revision `7087962223b49ee29a51ce06be98d5195dc39607` as the development baseline. The original README and credits are preserved in [source/UPSTREAM.md](source/UPSTREAM.md), including u/PunyFlash's [Bongo-Cat](https://github.com/PunyFlash/Bongo-Cat) and SoroCario.

The frog artwork and adopted laughter reference/video/audio were supplied or generated during this project's development. Frozen final artwork, reference images, generation prompts, and processing tools are retained in the source and preview directories.

Component licenses remain with their components:

- Native OBS plugin: [GPLv2 text](source/obs-native/LICENSE.txt), also distributed in [obs-input-overlay/LICENSE.txt](obs-input-overlay/LICENSE.txt).
- SFML 2.6.2 and its bundled dependencies: [SFML license and third-party notices](source/vendor/SFML-2.6.2/license.md).
- Input Overlay is installed separately from [univrsal/input-overlay](https://github.com/univrsal/input-overlay); OBS Studio is installed separately from [obsproject/obs-studio](https://github.com/obsproject/obs-studio).
