# 本地内存与存储优化（2026-11-17）

GitHub v1.2.0 已发布的是边缘修正版。本目录记录另行完成的本地低占用版，源码位于本工作树 `source/`；尚未上传本地优化提交。

| 项目 | 边缘修正版 | 低占用版 |
| --- | ---: | ---: |
| 单文件 EXE | 25.60 MB | 14.92 MB |
| 展开运行文件 | 27.20 MB | 16.52 MB |
| 待机工作集（含启动器） | 201.50 MB | 96.95 MB |
| 四键持续渲染工作集 | 175.85 MB | 103.08 MB |
| 启动工作集峰值 | 372.62 MB | 132.60 MB |
| 启动进程私有提交峰值 | 275.85 MB | 81.82 MB |

MB 按 1,000,000 字节计算。内存为本机实测，随驱动和系统状态变化；工作集包含共享/映射页，不等同于任务管理器的专用工作集或单独显存。待机值累计启动器和桌宠；四键及峰值在相同隐藏渲染基准中测量。私有提交明细见 JSON。保留完整原始采样，未用强制清空工作集制造下降。

修改：

- 32 个手势仅上传可见范围及两像素透明留白；阴影保留同样的原始位置。移除普通运行中重复的旧 4K 手势纹理；阴影生成后释放供体纹理。
- 构建时把运行图集从每格 1189×669 压紧到 460×330，通过偏移恢复位置，降低 PNG 解码峰值；素材源图仍保留。
- 单文件仅包含当前实际需要的运行文件；所有模式共用同一套 32 手势。
- 普通双击启动后启动器退出；带参数的导出与验收仍等待子程序并传回退出码。
- 采用已有 WebP 0.95 颜色质量打包；动画保留 720×720、24 fps、216 帧、9 秒，全部 alpha 逐像素无损。动画颜色使用有损编码；待机和敲键画面未重编码。

验证：

- 32 个紧凑手势的透明度、可见 RGB 和位置完全一致。
- 194 张原生状态、缩放及标签 PNG 与发布版逐像素一致；69 张 OBS 部件逐像素一致。
- 496 种按键组合、1776 个按下与 1776 个松开接触点通过。
- OBS 496 种生产 GPU 合成通过，alpha 最大误差 0，RGB 最大误差 1。
- 最终安装包的改键、大笑、按键取消、恢复待机、退出淡出与透明窗口检查通过；216 帧使用 Windows WIC 全部解码通过。
- 普通无参数启动后启动器确实退出，桌宠正常运行并能完成退出动画。

重新构建：在 `source/` 运行 `./build.ps1`，再运行 `python tools/BuildPortableExe.py`。运行 `python tools/VerifyRuntimeHands.py` 检查紧凑图集。`tools/MeasureRuntimeMemory.ps1` 使用原有隐藏粒子基准采样进程工作集和私有提交。
